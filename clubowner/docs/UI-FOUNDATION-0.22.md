# أساس الواجهة 0.22b — البنية قبل الهوية

مرحلة أولى من ثلاث (بنية → ميزات → هوية بصرية). الهدف: إصلاح نواقص الواجهة **البنيوية** دون تغيير الهوية البصرية، بحيث تكون مرحلة الهوية لاحقًا تعديل tokens لا إعادة شغل.

## ما تغير

### 1. نظام التصميم (`src/styles/tokens.css`)
مصدر واحد للألوان (بطبقاتها الحالية دون تغيير القيم الفعلية)، المسافات، الانحناءات، الظلال، أزمنة الحركة، وترتيب الطبقات z-index. تغيير الهوية لاحقًا = تعديل هذا الملف فقط.

### 2. طبقة الحركة (`src/styles/motion.css`)
- انتقال دخول لكل شاشة (`page-in`) مع تدرّج ظهور للبطاقات — يُفعَّل فقط عند تغيّر المسار، لا عند أي إعادة رندر (تبويب أو إجراء داخل نفس الشاشة لا يومض).
- تفاعلات دقيقة: ضغط الأزرار، رفع الصفوف التفاعلية عند المرور، نبض شارة عدم القراءة.
- حالة انشغال حقيقية أثناء تمرير الوقت/الحفظ: شريط تقدم علوي + تعتيم خفيف + منع النقر المزدوج (`body.saving-game` كانت تُضاف بلا أي CSS قبل ذلك). الشريط يعتمد transform فقط فيستمر حتى أثناء انشغال المحرك.
- ظهور النوافز والتنبيهات بحركة ناعمة، وهياكل تحميل (shimmer) للاستخدام اللاحق.
- `prefers-reduced-motion` يوقف كل ما سبق.

### 3. تنظيم التنقل (`src/components/shell.js`)
- القائمة الجانبية: من 15 عنصرًا متتاليًا إلى **5 مجموعات معنونة** (نظرة عامة / كرة القدم / الأعمال والمال / عالم الكرة / النظام). المعرفات `data-nav` كما هي، فلا شيء ينكسر في الاختبارات أو الترحيل.
- نافذة «المزيد» على الموبايل تعرض نفس المجموعات بعناوين.
- شريط الموبايل: الفريق الأول بدل المنشآت (استخدام أعلى)، وإزالة شارة «جديد» القديمة على الأساطير.
- توحيد رقم الإصدار الظاهر (0.22) في الشريط الجانبي وشاشة البداية والإعدادات ووسم index.html.

### 4. مقروئية الخطوط
مسح واحد على ملفات CSS الخمسة: 486 تصريحًا — كل الأحجام 8–13px رُفعت درجة أو درجتين (الحد الأدنى الآن 10px بدل 7px في بعض العناصر)، مع الحفاظ على كثافة القائمة الجانبية وعرضها (238px) حتى لا تطول بلا داع.

## ما لم يتغير

الهوية اللونية، الخط الأساسي (Cairo 16px من readability.css)، بنية الشاشات، المحرك، الحفظ، الترجمات (أُضيف 4 مفاتيح مجموعة فقط، والتغطية EN/FR ما زالت 0 ناقص).

## التحقق

```sh
npm test                              # 233 اختبار محرك — نجحت
node tests/ui-smoke.mjs               # جديد: رندر كل مسار عبر Node بلا متصفح
npm run i18n:coverage                 # 0 عبارة بلا ترجمة
npm run test:browser                  # المسار الرسمي كاملًا: أخطاء [] وتجاوز []
```

فحص إضافي خارج المستودع: 30 شاشة (15 مسارًا × سطح مكتب 1440/موبايل 390) بلا تجاوز أفقي وبلا أخطاء JS، مع التحقق من عمل الأنيميشن وحالة الانشغال عبر MutationObserver.

## حدود

- لم يُختبر على WebKit/آيفون فعلي هنا (بيئة التطوير الحالية بلا متصفح WebKit) — يشغَّل `npm run test:webkit` و`test:iphone` على بيئة بها المتصفحات.
- لقطات المراجعة في `review/` أعاد اختبار المتصفح توليدها بالشكل الجديد.
- المرحلة التالية المقترحة: تقرير المباراة الغني (نتيجة + أحداث + إحصائيات + تقييمات)، ثم البحث السريع، ثم الهوية البصرية عبر tokens.
