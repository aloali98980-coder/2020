# Club Owner — نظام الحسابات والمزامنة السحابية (v0.22.0)
_Club Owner Cloud Accounts & Multi-Device Sync Architecture_

---

## ١. نظرة عامة (Overview)

تم بناء نظام الحسابات والمزامنة السحابية في الإصدار **v0.22.0** لتمكين اللاعبين من:
1. **إنشاء حساب مجاني أو تسجيل الدخول** (بريد إلكتروني، اسم مستخدم، كلمة مرور مشفرة).
2. **المزامنة السحابية بنقرة واحدة** لمسيرتهم التدريبية والإدارية، مع ضغط البيانات باستخدام `pako` (gzip) وترميز `Base64` لتقليل استهلاك النطاق الترددي وحجم التخزين.
3. **التنقل بسلاسة بين الأجهزة** (من الكمبيوتر إلى الهاتف أو العكس) عبر زر **"استرجاع من السحابة"** في شاشة البداية (Setup) وشاشة الإعدادات (Settings).
4. **نافذة فحص الفروقات قبل الاسترجاع (Diff Inspection)**: تعرض مقارنة حية بين النادي، الموسم، التاريخ، والسيولة النقدية للحفظة المحلية الحالية والحفظة السحابية، لتجنب أي استبدال غير مقصود.
5. **إدارة النسخ الاحتياطية (Cloud Saves History)**: الاحتفاظ بأحدث ٥ نسخ سحابية مع إمكانية استعراضها وحذف القديم منها.

## ٢. البنية التقنية (Architecture & Components)

### أ. الخادم ونقاط الـ REST API (`server/`)
- **`server/cloudStore.js`**:
  - قاعدة بيانات محلية JSON للمستخدمين والجلسات والحفظات السحابية (`cloud-data.json`).
  - تشفير كلمات المرور باستخدام خوارزمية **`crypto.scryptSync`** مع Salt فريد من ١٦ بايت لكل مستخدم.
  - إدارة الرموز (Tokens) الفريدة لكل جلسة (`crypto.randomBytes(32)`).
  - تحديد سقف ٥ حفظات كحد أقصى لكل حساب مع تنظيف تلقائي للنسخ الأقدم (Auto-pruning).
- **`server/cloudHandler.js`**:
  - معالج طلبات HTTP REST API يدعم CORS و Bearer Token:
    - `POST /api/auth/register` (تسجيل حساب جديد)
    - `POST /api/auth/login` (تسجيل الدخول)
    - `POST /api/auth/logout` (تسجيل الخروج)
    - `GET /api/auth/me` (التحقق من الجلسة النشطة)
    - `POST /api/cloud/sync` (رفع وحفظ مسيرة سحابية)
    - `GET /api/cloud/saves` (قائمة الحفظات)
    - `GET /api/cloud/saves/latest` (جلب أحدث حفظة)
    - `GET /api/cloud/saves/:id` (تحميل حفظة محددة)
    - `DELETE /api/cloud/saves/:id` (حذف نسخة)
- **`server/viteCloudPlugin.js`**: إضافة Vite Middleware تتيح تشغيل خادم المزامنة أثناء وضع التطوير (`npm run dev`) والمُعاينة (`npm run preview`).
- **`server/index.mjs`**: خادم إنتاجي مستقل وخفيف مبني بـ Node.js خالص لخدمة ملفات `dist` الثابتة ونقاط المزامنة السحابية في بيئة الاستضافة دون الحاجة لأي مكتبات خارجية.

### ب. خدمات العميل (`src/services/`)
- **`src/services/auth.js`**:
  - إدارة الجلسة المحلية في المتصفح (`clubowner.auth.session`).
  - دوال `authRegister`, `authLogin`, `authLogout`, `isAuthenticated`, `getAuthUser`.
- **`src/services/cloud.js`**:
  - استخراج لقطة المسيرة من IndexedDB / LocalStorage عبر `exportSavePayload`.
  - ضغط الحفظة عبر Gzip Base64 لتقليص الحجم بنسبة تصل إلى ٨٥٪.
  - دالة `compareCloudWithLocal(localState, cloudSave)` لحساب الفروقات بذكاء حتى لو كان المتصفح جهازًا جديدًا تمامًا لا يحتوي على حفظة سابقة.

### ج. واجهة المستخدم (`src/features/` & `src/main.js`)
- **لوحة السحابة في الإعدادات (`cloudPanel`)**:
  - إظهار حالة تسجيل الدخول واسم المستخدم والبريد وتاريخ آخر مزامنة.
  - أزرار سريعة: "مزامنة الآن إلى السحابة"، "استرجاع من السحابة"، "إدارة الحفظات"، و"تسجيل الخروج".
- **شاشة الإعداد (`setupView`)**:
  - زر في تذييل الشاشة `[data-action="cloud-restore-prompt"]` يتيح للاعب عند فتح اللعبة لأول مرة على جهاز جديد تسجيل دخوله واستعادة مسيرته فورًا دون الحاجة لبدء نادٍ جديد.
- **نافذة مقارنة الحفظة (`.cloud-diff-grid`)**:
  - مقارنة بصرية جنباً إلى جنب بين النادي المحلي والنادي السحابي.
