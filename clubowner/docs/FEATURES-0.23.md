# 0.23 — «المظهر»: هوية بصرية جديدة وعملة عرض

> إصدار الهوية البصرية. أول وضع فاتح في اللعبة، وتدرّج أزرق ملكي وذهبي،
> وعملة عرض مستقلة عن محرك الحسابات.

## القرار

اعتُمد الاتجاه **ب: أزرق ملكي وذهبي** (من بين ثلاثة اتجاهات في `docs/theme-preview.html`)
مع **وضع فاتح كامل** (داكن + فاتح + حسب النظام).

## الجديد

| الميزة | التفاصيل |
| --- | --- |
| هوية بصرية جديدة | أزرق ملكي `#5b9dff` + ذهبي `#e3b84e` على خلفيات كحلية عميقة؛ كل الألوان عبر توكنز `tokens.css` (~200 لونًا حرفيًا رُحّلت) |
| وضع فاتح كامل | `[data-theme="light"]`: خلفيات `#f2f6fb`/أبيض، أزرق أغمق للتفاصيل `#1f6fd9`، ذهبي متكيف `#a87a1c` |
| الثيم «حسب النظام» | `clubowner.theme = "system"` يتبع `prefers-color-scheme` ويستمع للتغيير لحظيًا |
| بلا وميض | سكربت مبكر في `index.html` يطبق الثيم وحجم الخط **قبل أول طلاء**، ويحدّث `theme-color` للمتصفح |
| حجم الخط | عادي / كبير (`clubowner.fontsize`) — تكبير ١٫١٢× للقشرة والتنقل والنوافذ |
| عملة العرض | قسم «المظهر والواجهة» في الإعدادات: ج.م (افتراضي)، $، €، £، ر.س، د.إ — تحويل فوري لكل المبالغ المعروضة |
| ملاحظة الأسعار | «الأسعار نموذجية ثابتة للعرض؛ كل الحسابات تتم بالجنيه» — أسعار `perEGP` ثابتة من `currencies.js`، لا أسعار حية |
| تصحيح الووترمارك | «EST. 2026 / YOUR ERA» الإنجليزي الثابت → «منذ ٢٠٢٦ · عهدك أنت» مترجمًا بثلاث لغات |

## حدود التصميم (دائمة)

- **العملة عرض فقط**: كل الحفظ والمحاكاة والالتزامات بالجنيه المصري. التحويل يحدث في
  `money()`/`cur()` عند العرض فقط. تغيير عملة المحرك مرفوض.
- التفضيلات (الثيم/الخط/العملة/اللغة) في `localStorage` خارج الحفظات — لا تسافر مع
  ملف الحفظ بين الأجهزة.
- أي لون جديد يُضاف مستقبلًا يجب أن يمر عبر `tokens.css` بقيمتين (داكن/فاتح).

## التقنية

- `src/styles/tokens.css`: نظام توكنز كامل — ألوان لكل ثيم، `--wash`، `--hero-grad`،
  `--gold-ink`، طبقات `--z-*`، وأسماء قديمة (`--green`، `--panel2`) كأسماء بديلة للتوافق.
- `src/ui/format.js`: `setDisplayCurrency()`/`getDisplayCurrency()`/`cur()`؛
  `money()` يحوّل بالسعر الثابت ويقرّب لأقرب صحيح.
- استُبدلت 95+ كتابة «ج.م» حرفية في القوالب بـ`${cur()}` عبر `src/features`, `src/services`,
  `src/components`, `src/main.js`.
- `responsive.css`/`readability.css` صارا خاليين من الألوان الحرفية (فيد الهيرو، شريط
  التنقل للموبايل، رقائق التشكيل… كلها `color-mix` على التوكنز).
- فجوات القاموس الناتجة عن تقسيم العبارات عند رمز العملة سُدّت (34 مدخلًا جديدًا).
