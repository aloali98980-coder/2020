# المرحلة 13 — المجموعة الرابعة: المعارضة والنزاهة والعلاقات الخارجية والإرث

**الإصدار:** 0.34.0 · **إصدار الحفظ:** 30
**المجموعة:** معارضة الاتحاد، المساءلة، الدبلوماسية، وما بعد المنصب.

## ما أُضيف

- ضغط معارضة شهري يتأثر بالشرعية والنزاهة والتحقيقات. يفتح اقتراح حجب ثقة تدريجيًا، ثم يجري اقتراعًا اسميًا بأوزان الأندية؛ خسارة التصويت تنهي الولاية مبكرًا وتعيد جدولة الانتخابات.
- الرد على الانتقادات عبر الإفصاح المالي أو جلسة استماع أو التصعيد. لكل خيار أثر مختلف مسجل على الشرعية والنزاهة والضغط؛ التصعيد يترك أثرًا سلبيًا واضحًا.
- إقرار سنوي بأصول الاتحاد، وتدقيق نزاهة يربط مراجعة الخزينة بسجل النزاهة. تسجل المنح لنادي الرئيس والأحكام التأديبية التي تفيده كحالات تعارض مصالح؛ الإفصاح والتدقيق النظيف يقللان أثرها.
- تحقيقات محددة النطاق في المنح، والانضباط، والمسابقات، وتمويل الحملات. لكل ملف تاريخ استحقاق وأدلة أولية وقرار تبرئة أو إحالة. التحقيقات الجادة قد تفتح ملفًا قضائيًا بعد المنصب.
- بعثات دبلوماسية إلى خمس جهات كروية دولية لتحسين العلاقات والنفوذ مقابل تكلفة مسجلة. ملفات الاستضافة تُحسم بعد 30 يومًا بمعيار معلن يجمع العلاقة والنزاهة والشرعية والنفوذ، وتُسجل المكافأة إن فاز الاتحاد.
- مقعد تنفيذي دولي مشروط بالعلاقة والنفوذ والنزاهة، لمدة أربعة مواسم، وتكلفة موثقة في دفتر الاتحاد.
- إنهاء الولاية أو خسارة الانتخابات أو حجب الثقة يؤرشف سجلًا يحسب النزاهة والشرعية والقوانين والتدقيقات النظيفة. تُمنح أوسمة الإصلاح والنزاهة، وقد يبدأ ملف قضائي عند السجل المنخفض؛ يمكن للرئيس السابق التعاون أو الطعن.
- ترحيل آلي ومحايد v29→v30 يضيف الحقول الناقصة دون إعادة ضبط الضغط أو العلاقات أو النزاهة المحفوظة أو سجل الإرث.
