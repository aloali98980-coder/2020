# تقرير مرحلة آسيا — 0.11

## إيه اللي خلص فعلًا؟

**البطولات الآسيوية الثلاث بقت قابلة للعب من التأهل لحد تتويج البطل.** ده إنجاز مرحلة المسابقات الآسيوية، مش إعلان إن اللعبة كلها خلصت أو إن كل لوائح AFC الرسمية اتنفّذت.

- **النخبة:** 32 ناديًا، شرق وغرب، 8 مباريات لكل نادٍ، ثم ثمن نهائي ذهاب وإياب ونهائيات مجمعة.
- **دوري الأبطال 2:** 32 ناديًا، 8 مجموعات، إقصائيات إقليمية ونهائي واحد.
- **التحدي:** 20 ناديًا، 5 مجموعات، تأهل مختلف للشرق والغرب، ثم ربع ونصف نهائي ونهائي.
- انتقال الخاسرين من تمهيدي النخبة للثانية، ومن تمهيدي الثانية للتحدي؛ ومسارات الموسم التالي لحاملي الألقاب ووصيف التحدي.
- 53 ناديًا حقيقيًا في قائمة ضيوف مرجعية، لتغطية بلدان خارج الدوريات المحمّلة. الضيوف مش دوريات جديدة ومش أندية قابلة للاختيار، ومفيش ادعاء بإضافة قوائم لاعبين مرخّصة ليهم.
- قرعات وترتيب ونتائج ووقت إضافي وترجيح وجوائز نموذجية وأرشيف، وربط بطل النخبة ببطولات FIFA، حتى لو كان ناديًا ضيفًا.
- **نطاق الدوريات والصعود ما اتغيرش:** 116 مسابقة في العالم الكامل، ونفس الاستثناءات المتفق عليها للمغرب وبوليفيا وقطر.

## اتختبر إيه؟

| الاختبار | النتيجة الفعلية |
|---|---|
| اختبارات المشروع الآلية | **140 ناجحًا من 140**، منها 14 اختبارًا جديدًا لآسيا |
| العالم الكامل — 50 سوقًا و116 مسابقة | **3 مواسم كاملة**؛ آسيا 155/129/43 مباراة كل موسم؛ كأس العالم 2029 و3 نسخ إنتركونتيننتال مكتملة |
| استقرار محرك آسيا منفردًا | **40 موسمًا معزولًا** للتأهل والألقاب والقرعات؛ ليس اختبار عالم كامل أو سعة لاعبين لعقود |
| تنويع قرعة النخبة | 40 بذرة لكل منطقة؛ 8 خصوم مختلفين، 4 داخل و4 خارج، بلا مواجهة نفس الاتحاد |
| اللعب بنادٍ آسيوي مملوك | مشاركات فعلية للقائمة، تحصيل ملعب، وعدم تحصيل التذاكر في موقع محايد أو تكرار التحصيل |
| تقويم العالم | فحص يومي في الموسم الكامل الأول؛ فاصل تواريخ لا يقل عن 3 أيام |
| موبايل 390px — Chromium وWebKit | عرض البطولات والجداول والإقصائيات، بداية بنادٍ آسيوي، تقدم يوم وإعادة تحميل، بلا أخطاء JavaScript أو تجاوز عرض الصفحة |
| حفظ العالم الكامل أثناء المجموعات والإقصائيات | استيراد فعلي وإعادة تحميل IndexedDB وتصدير مطابق بالبايت في المتصفحين؛ كل حفظة كبيرة اختُبرت في **عملية متصفح مستقلة** |
| ترحيل 0.10 الحقيقي | 80 يومًا بالمحرك القديم، ثم 10 أيام مقارنة متطابقة عدا بيانات الترحيل؛ تشغيل آسيا بعد نهاية الموسم فقط |
| دون اتصال | ناجح في Chromium؛ لا اعتماد جديد لأوفلاين WebKit أو آيفون فعلي |

اختبار العالم انتهى بـ**49,037 لاعبًا** مع بقاء كل الهويات الأصلية، وملف خام حجمه 110,774,705 بايت، أو 9,811,185 بايت مضغوطًا في اختبار Node. زمن الاختبار 229.4 ثانية على بيئة التطوير، وليس وعدًا بسرعة الهاتف.

## إيه اللي لسه مبسّط أو ناقص؟

- حصص البلدان، أوعية السمعة، التمهيدي، المواعيد، الاستضافة والجوائز **محاكاة معلنة**؛ مش قوائم دخول وترخيص أو تقويم رسمي معتمد. لا تمهيدي مستقل للتحدي ولا مسار مستقل لبطل الكأس المحلي في التأهل الآسيوي حاليًا.
- ضيوف البلدان غير المحمّلة بيتحاكى أداؤهم بخفة، مش بدوري وقائمة لاعبين تفصيلية. الانضباط سجل فريق محاكى، مش إيقافات فردية كاملة.
- نجاح 3 مواسم **ما يحلّش سقف 50,000 لاعب**. تحسين السعة للمشوار الطويل مطلوب قبل النسخة النهائية.
- **حد ذاكرة رُصد ولم يُحل:** استيراد حفظتين كاملتين تباعًا داخل عملية WebKit واحدة أدّى لنفاد ذاكرة بيئة الاختبار ذات 2 GiB. نجحت كل حفظة منفردة بعد إعادة تشغيل المتصفح؛ ده توثيق للحد، مش إصلاح له. تحسين ذروة الذاكرة واختبار آيفون فعلي باقيان.
