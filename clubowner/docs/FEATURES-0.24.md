# 0.24 — «Empire FC»: هوية اللعبة الجديدة

> إصدار الهوية. الاسم الإنجليزي **Empire FC** مع الشعار اللفظي «ابنِ إمبراطوريتك»،
> وشاشة بداية تتكلم لغة اللاعبين بدل لغة التطوير، وصفحات المصادر والتراخيص
> بالهوية الملكية (كحلي + ذهبي) بدل الأخضر القديم.

## القرار

الاسم الذي يراه اللاعب صار **Empire FC** في كل موضع هوية: البراند، عنوان التبويب،
اسم التطبيق المثبَّت (PWA)، وأسفل السايدبار. أما النصوص التي كانت تصف اللعبة
بلغة المطورين («نسخة تجريبية قابلة للعب»، «نسخة تطوير مستقلة»، «سيناريو اختبار ·
عالم تجريبي»، «حزمة 0.2 القديمة») فإما حُذفت أو أُعيدت كتابتها بلغة اللاعب.

## ما لم يتغيّر (مقصود)

- المحرك، البيانات، الحفظات والترحيل، القاموس الثلاثي، الألوان داخل اللعبة
  (`tokens.css`) — لم تُمسّ. التغيير هوية ونصوص قشرة فقط.
- الحفظة القديمة تفتح كما هي؛ لا تغيير في مخطط الحفظ ولا في `APP_VERSION` كرقم
  ترحيل (رقم الإصدار ما زال مصدره الوحيد `src/data/version.js`).

## متبقيات معروفة (لم يشملها سكربت 0.24)

الاسم العربي القديم ما زال ظاهرًا في مواضع لم يدخلها السكربت، وتُترك لإصدار تالٍ
أو لقرار صريح:

- `index.html`: وسم `<meta name="description">` («صاحب النادي — لعبة إدارة وملكية نادي كرة قدم»).
- `src/platform/install.js`: دليل التثبيت على آيفون يقول «افتح أيقونة **صاحب النادي**» بينما اسم الأيقونة صار Empire FC.
- عناوين صفحات التراخيص (`competition-notes.html` وغيرها) ما زالت تذكر «صاحب النادي» و`CLUB OWNER` في النص.
- مدخلات القاموس القديمة المرتبطة بالاسم السابق (مثل `phrases-ui.js`) صارت غير مستخدمة بعد إعادة كتابة وصف «عن اللعبة».

## التقنية

- `apply-0.24.mjs` في جذر المستودع: سكربت التطبيق الكامل (استبدالات نصية صريحة +
  أنماط regex محدودة + إعادة تلوين الصفحات الثابتة). يُشغَّل مرة واحدة من الجذر:
  `node apply-0.24.mjs` — ويخرج برمز فشل لو أي استبدال لم يجد نصه، ويبقى خاملًا
  (حارس تكرار) لو طُبّق الإصدار بالفعل.
- `src/data/version.js` → `APP_VERSION = "0.24"`، و`package.json` (الجذر و`clubowner/`)
  → `0.24.0`، ووسم meta في `index.html` → `0.24.0`.
- `shell.js` و`expanded.js` استوردا `tr` من `src/i18n/index.js` لأن نصوصهما الجديدة
  مترجمة بثلاث لغات بدل نص عربي ثابت.
- `tests/version.test.js` حُدّث لـ0.24: شارة `v${APP_VERSION}` بدل `ALPHA` في «عن
  اللعبة»، فحص أن شاشة البداية خالية من ALPHA و`version-pill`، وفحص جديد لهوية
  Empire FC (العنوان، المانيفست، البراند، عناوين `main.js`).

## النشر

1. الدفع إلى الفرع، ثم دمجه في `main` — Cloudflare Workers مربوط بالمستودع ويبني
   تلقائيًا: Deploy command = `npm install && npm run build && npx wrangler deploy`،
   Root directory = `clubowner` (أو جذر المستودع مع `wrangler.toml` الجذر).
2. بعد النشر يجب أن يعرض <https://2020.aloali98980.workers.dev> اسم **EMPIRE FC**
   في البراند وعنوان التبويب، و`v0.24` أسفل السايدبار.
3. من عنده نسخة مثبتة (PWA) سيحصل على التحديث تلقائيًا لأن كاش الأوفلاين تغيّر
   اسمه مع البناء الجديد.
